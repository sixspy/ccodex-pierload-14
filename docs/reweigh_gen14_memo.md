# 二次升代纪要（第14号）

- 日期：2026-11-24，当日封死。
- 案由：二次过磅时旧票 PL-N14a 未作废、新票 PL-N14b 已正式入库，同车（沪N·集1414）同提单（BL-2026-0114）双正式并存，血缘与对账双计。

## 拍板：甲路径

再次过磅须**同事务作废旧票并升新代正式，正式票零净增，否则整笔回滚**。

- 乙路径（影子新代＋晋升时原子切换）否决。
- 折中禁止。双口径会让同车双正式并存。
- 禁止只改过磅页版本角标。

## 互斥口径

1. 互斥域：`(车牌, 提单)` 维度正式票（状态非「作废」）唯一。
2. 写路径：`POST /api/tickets/reweigh`，同事务内作废旧票、登记「二次过磅升代」血缘边、升新代正式；任一步失败整笔回滚。
3. 初磅 `POST /api/tickets` 遇同车同提单已有正式票：记「二次升代偏航」并拒写（409），不得绕过升代互斥。
4. 旧票已锁态（已封闸/已放行）或超重挂起未闭环：拒升代。
5. 偏离本纪要的写请求（如 `mode=乙` 等影子口径）：记审计「二次升代偏航」并拒写。

## 争用

- 双人同车号抢二次过磅须抢车号锁 `vehicle:{车牌}`；后到只留争用痕（409 + contention_log），不写业务。

## 五页同源

过磅页、血缘页、对账页、快照页、车道页同读 `weigh_tickets` 单一事实源：作废/正式/闸代各页一致，不得各执一口径。

## 对账与封闸

- 对账按互斥口径只计各车最新正式票；检出同车双正式即报 `double_formal` 冲突、判不平衡、禁出证明，不得双计。
- 同车双正式未解，封闸拒写（409）。

## 纪律

- 三红见证后方准改血缘服务、封闸服务、过磅服务、对账服务与血缘页、快照页。
- 收工三绿；未见证红禁止合入。
